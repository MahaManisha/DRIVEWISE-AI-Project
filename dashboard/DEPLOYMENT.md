# DriveWise Dashboard Deployment Guide

This guide describes how to deploy the **DriveWise React Dashboard** to **Render** and configure it correctly.

---

## 🏗️ Architecture & Setup Overview

The DriveWise AI project is a split-architecture application:
1. **Frontend (Vite + React Dashboard)**: Displays live telemetry, charts, logs, and alerts. This can be deployed to **Render as a Static Site**.
2. **Backend (Python Drowsiness Detection)**: Runs on the driver's local machine. It captures physical webcam video frames, performs CPU/GPU machine learning model inference (MediaPipe and YOLO), and plays local TTS/audio alerts.

> [!IMPORTANT]
> Because the Python backend needs physical camera access and audio speaker access, **it must be run locally** on the host machine where the camera is situated. It cannot run in the cloud (Render) because cloud containers are headless (no webcam attached) and have tight CPU/memory limits.

---

## 🚀 Step 1: Deploying the Dashboard on Render

1. Log into [Render](https://render.com/).
2. Click **New +** and select **Static Site**.
3. Connect your GitHub repository: `MahaManisha/DRIVEWISE-AI-Project`.
4. Configure the build settings as follows:
   - **Name**: `drivewise-dashboard` (or any name you prefer)
   - **Branch**: `main`
   - **Root Directory**: `dashboard`
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
5. Click **Create Static Site**. Render will automatically pull the code, install dependencies, and build the React app.

---

## ⚡ Step 2: Running the Project

### Option A: Interactive Showcase Mode (Default)
Once deployed, if the dashboard is opened in a browser and cannot connect to a running local Python server, it will automatically activate the **Interactive Offline Simulation** (using simulated real-time mock data).
- This is perfect for sharing a live preview link with recruiters, stakeholders, or users without requiring them to install Python or set up a webcam!

### Option B: Local Live Camera Connection (Mixed Content Handling)
If you want your deployed Render dashboard to talk to your local python server, you will need to bypass the browser's **Mixed Content Blocker** (browsers block HTTPS websites from making unsecured HTTP requests to `localhost`).

To connect them:
1. Run your Python server locally (starts on `http://127.0.0.1:8000`).
2. Expose a secure HTTPS endpoint for your local server using a tool like **ngrok**:
   ```bash
   ngrok http 8000
   ```
3. Copy the secure HTTPS URL generated by ngrok (e.g. `https://xxxx.ngrok-free.app`).
4. In your Render Static Site settings, go to the **Environment** tab and add:
   - **Key**: `VITE_API_BASE_URL`
   - **Value**: `https://xxxx.ngrok-free.app/api`
5. Redeploy the static site on Render. Now, the deployed dashboard will pull live telemetry and camera feed streams directly from your local machine over a secure channel!
